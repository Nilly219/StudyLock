01Is StudyLock actually free?−
Yes — StudyLock is free with no account required. There is no trial period or hidden paywall for the current features.
02Does it work on Brave, or only Chrome?+
Both. StudyLock is built on the standard Chromium extension APIs, so it installs and runs the same way on Chrome and Brave.
03Does StudyLock collect or send my data anywhere?+
No. Sessions, tasks, and blocked-site lists are stored locally in your browser only. Nothing is synced to a server.
04Can I choose which sites get blocked?+
Yes — you pick the exact list. Nothing is blocked by default, and you can edit the list at any time between sessions.
05What happens if I close my browser mid-session?+
Your session state is saved locally, so reopening the browser picks the timer and lock list back up where you left off.
06Can I end a session early if I need to?+
Yes. There's an End button in the popup for whenever a session genuinely needs to stop early — no penalty, no streak lost.
07Will it slow down my browser?+
No. Outside an active session the extension is idle, and blocking is handled by the browser's own request rules, not a background script.
08Is there a mobile version?+
Not yet — StudyLock currently ships as a Chrome and Brave desktop extension only. Mobile isn't ruled out, just not built.
